INNOVATION PROJECT TRACKING SYSTEM - SIMPLE WEB PROTOTYPE

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or open it in Chrome/Safari/Edge.
4. Use “Add New Project” to add a project.
5. Search, filter, edit, and delete project records.

FEATURES
- Dashboard summary cards
- Add, edit and delete project records
- Search by project name, description or team
- Filter by project status
- Track progress from 0% to 100%
- Automatically marks a project Completed when progress is 100%
- Saves demo data in the browser using localStorage

IMPORTANT PROJECT NOTE
This is a front-end demonstration built with HTML, CSS and JavaScript. It is not a Java backend application and does not implement Java syllabus concepts by itself. If the academic submission requires Java implementation, the team should build/connect a Java application separately and document only concepts that are genuinely implemented.
